# CongosMods wiki: notes for Claude

- This repo is **public** and builds the wiki at https://therealcongo.github.io/CongosMods/. The mods' source repos are private: never copy their code or internal docs here.
- To update the wiki after a Workshop release, or to add a mod, follow the `/wiki-update` skill (`.claude/skills/wiki-update/SKILL.md`). Propose first, and push only after the user approves that proposal.
- `main` is protected: every change goes through a PR that must pass the **Build check**. Use task-named branches (`wiki/<mod>-<version>`), never machine-named ones (Laptop, Desktop).
