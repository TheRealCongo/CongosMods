# Getting Started

## Installing a mod

1. Open the game's **Workshop**.
2. Search for the mod's name, or use the Workshop link on that mod's wiki page.
3. Click **Subscribe** / **Download**.
4. Enable the mod before you join a server or start a scenario.

!!! note
    Some mods depend on other mods. Each mod's page lists its **dependencies**, and the Workshop usually downloads them for you.

## Updating

Mods update automatically through the Workshop. Check a mod's **Changelog** section to see what changed.

## Running the mods on a server

Each mod page has a **Server setup** section listing what to add to your server config.
