# All Mods

Every mod has its own page with features, screenshots, setup instructions and a changelog.

| Mod | Summary | Status |
|-----|---------|--------|
| [Dynamic Lights](dynamic-lights.md) | A complete working power grid: every light runs on the map's real power lines, and players can shut off, disrupt and restore them. | :material-check-circle:{ style="color: #4caf50" } Released |
| [Mission Architect](mission-architect.md) | Build PvE missions live as Game Master: triggers, spawners, objectives and fire support, linked together and saved. | :material-check-circle:{ style="color: #4caf50" } Released |
| [Tactical Deployables](tactical-deployables.md) | Field gear you carry, set up and pack away: sniper tripod, spotting scope and rangefinder, mast antenna, camo nets, tape, trip flares, chemlights and marker panels. | :material-check-circle:{ style="color: #4caf50" } Released |
| [Weather System](weather-system.md) | Smooth GM-timed weather changes, three rain levels, thick and thin fog, ground fog, lightning storms, rain on roofs and wind gusts. | :material-check-circle:{ style="color: #4caf50" } Released |
| [Weather System - Desert](weather-system-desert.md) | Desert weather for Weather System: haboob dust walls, sandstorms, dry thunderstorms, dust devils and blowing sand. | :material-check-circle:{ style="color: #4caf50" } Released |
| [Example Mod](example-mod.md) | A one-line summary of the mod. | :material-check-circle:{ style="color: #4caf50" } Released |

!!! tip "Adding a new mod page"
    Copy `docs/mods/example-mod.md` to a new file (for example `docs/mods/my-new-mod.md`), fill it in, then add it to the table above and to the `nav:` list in `mkdocs.yml`.
